# Tangent 0.1.0

The first experimental release of Tangent, an independent open-source browser for people who want to keep browsing the Arc way.

Tangent was built after The Browser Company announced that it would discontinue Arc. It keeps the workflow that made Arc useful: Spaces, vertical tabs, Favorites, a command bar, split view, and Peek. It is an original implementation using Electron and Chromium, with no Arc installation or account required.

## What is included

- Real Chromium pages with navigation, search, find, zoom, downloads, and popups.
- Spaces, Profile-specific Favorites, pinned tabs, Today tabs, and an archive.
- Separate cookie and website-storage partitions for different Profiles.
- Two-page split view and Peek previews that retain their live page when promoted to a tab.
- Local session restore, history, JSON backup and restore, and light/dark themes.
- Manual installer updates and a tested source-update command.

This is early software. Chrome Web Store extensions, a password manager, private browsing, Arc import conversion, cloud sync, and default-browser integration are not implemented. Save work in websites before quitting or closing tabs; restoring a session restores addresses, not unsaved forms.

## Choose your download

| Computer | File |
| --- | --- |
| Mac with an Apple chip | `Tangent-0.1.0-mac-arm64.dmg` |
| Mac with an Intel processor | `Tangent-0.1.0-mac-x64.dmg` |
| Windows x64 | `Tangent-0.1.0-win-x64.exe` |
| Linux x64 | `Tangent-0.1.0-linux-x86_64.AppImage` |

Both Mac architectures also have ZIP copies. Download `SHA256SUMS` to check your file and `BUILDINFO.json` to inspect the exact source commit and bundled runtime versions.

## Install

**macOS:** Open the DMG and drag Tangent into Applications. Alternatively, extract the ZIP and move `Tangent.app` into Applications. These builds have an ad hoc signature, without an Apple Developer ID certificate or notarization.

**Windows:** Run the EXE installer and follow its prompts. The installer does not have a publisher certificate.

**Linux:** Make the AppImage executable and run it as your normal desktop user:

```sh
chmod +x Tangent-0.1.0-linux-x86_64.AppImage
./Tangent-0.1.0-linux-x86_64.AppImage
```

Linux packages require a working Chromium sandbox and unprivileged user namespaces. Release checks use Ubuntu 22.04. Restricted configurations, including default Ubuntu 24.04 policies, may block launch; this build does not disable the sandbox to work around them. The [README](https://github.com/davidjbeveridge/tangent#desktop-installers) also explains running an extracted AppImage when FUSE is unavailable.

The operating system may block an unsigned or unnotarized download. The [source installation](https://github.com/davidjbeveridge/tangent#from-source) is available if that happens. Keep operating-system protections and Chromium sandboxing enabled.

To verify a download, compute its SHA-256 hash and compare it with the matching line in `SHA256SUMS`:

```sh
# macOS
shasum -a 256 Tangent-0.1.0-mac-arm64.dmg

# Linux
sha256sum Tangent-0.1.0-linux-x86_64.AppImage
```

```powershell
# Windows PowerShell
Get-FileHash .\Tangent-0.1.0-win-x64.exe -Algorithm SHA256
```

A matching checksum confirms file integrity. It does not provide a publisher signature. Use assets from `davidjbeveridge/tangent` on GitHub.

## Start browsing

Press **Command+T** on a Mac or **Ctrl+T** on Windows/Linux to open a page. Create a Space for a project, right-click tabs to pin them, and create separate Profiles in Settings when you want separate website logins. Right-click a link to open it in split view or Peek.

The [README](https://github.com/davidjbeveridge/tangent#readme) covers shortcuts, local data, features, and limitations.

## Update

Open **Settings > About Tangent > Open releases**. Download the next package for the same operating system and architecture, verify its hash, quit Tangent, and install or replace the application. The normal browsing-data folder stays in place. Export a backup from Settings before a significant upgrade.

For a source installation, quit Tangent and run `npm run update` in its repository. The script stages and tests the new version before updating the working installation.

Chromium updates arrive through reviewed Electron updates and complete Tangent builds. This release does not install updates in the background or replace Chromium independently.
