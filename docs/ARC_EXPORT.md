# Save your Arc tabs before December 22, 2026

**Make an export now, check it, and keep a backup.** This checklist helps you preserve tab links whichever browser you choose next.

The Browser Company's [October 22, 2026 announcement](https://arc.net/) says Arc for macOS and Windows will stop working on **December 22, 2026**. New accounts closed on October 22; existing desktop users can continue using Arc with basic updates until the shutdown date. These are different dates and events.

The official export instructions below were checked on **October 22, 2026**. If Arc's interface or instructions change, follow its current [official guidance](https://arc.net/).

## On a Mac

1. Open **Arc > Settings** from the Mac menu bar.
2. Select **Advanced**, then **Export Data**.
3. Choose where to save the file, then select **Save**.
4. Complete the verification checklist below.

## On Windows

1. Open Arc's **Settings** with **Ctrl+,**, or choose Settings from the Arc menu.
2. Under **Advanced**, find **Export Spaces and tabs**.
3. Select **Export Data**, choose a location, and save the file.
4. Complete the verification checklist below.

## Check the export before you rely on it

- [ ] The exported file exists and is not empty.
- [ ] Open it using an appropriate local viewer and confirm the links you care about are present.
- [ ] Check several important links, including ones from different Spaces.
- [ ] Keep a backup somewhere you can find after switching browsers.
- [ ] Review passwords, extensions, and other browser data separately. Do not assume a tab export preserves every part of your setup.

An export can contain private or work-related URLs. Keep the file private and avoid uploading your real browsing history to a public issue or discussion.

## What the export does, and what Tangent can do with it

Arc's announcement describes the portable tab export as a **list of links**. Do not assume it transfers passwords, cookies, logged-in sessions, extension data, or unsaved page contents.

**Tangent has no Arc import converter yet.** Its JSON restore accepts backups created by Tangent, not Arc exports. You can open exported links manually and organize them into Tangent Spaces and pinned tabs. That does not transfer your previous browser's logins or recreate its entire workspace automatically.

Tangent is an independent, experimental browser. Try it alongside your current browser and read the [installation instructions and limitations](../README.md#install-and-run). It does not yet include Chrome Web Store integration, a password manager, private browsing, cloud sync, or default-browser integration. Its packaged builds use manual updates, with ad hoc signing without notarization on macOS and unsigned installers on Windows. Keep platform protections enabled.

If you want to help build a migration path, read [CONTRIBUTING.md](../CONTRIBUTING.md). Reproducible examples with synthetic tab data are useful without exposing personal browsing history.
